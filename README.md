# ctxmedic

> The context medic for your AI coding setup.

Local diagnostics, linting, auto-fixes and token FinOps for Claude Code, Cursor, Windsurf, Codex CLI, OpenCode, Cline and Copilot configs.

```
npx ctxmedic checkup
ctxmedic treat
ctxmedic savings
```
